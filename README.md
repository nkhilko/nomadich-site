# НОМАДИЧ — демонстрация кофейной витрины

Интерактивный фронтенд-прототип каталога кофе. В демо можно менять состав и количество позиций в корзине, проверять сумму в RSD и выбирать курьерскую доставку или самовывоз. **Реальные заказы и платежи не принимаются.**

## Запуск

Откройте `index.html` из локальной копии проекта. Стили, скрипт и изображения загружаются из этой же копии. Для работы демо не нужны сервер, интернет или учётные данные.

Добавьте кофе в корзину, выберите способ получения и заполните поля вымышленными данными. Завершите оформление кнопкой или нажмите Enter в текстовом поле. Подтверждение появляется на этой же странице, введённые значения очищаются.

У оформления нет отправляемой HTML-формы или сетевого обработчика. Приложение не сохраняет значения полей и не добавляет их в URL. Поля и кнопка выключены до инициализации JavaScript.

## Проверка

Статические проверки и проверка обработчика с вымышленными данными работают без зависимостей:

```sh
node --check app.js
node --test test/checkout.test.cjs
```

Для проверки в Chromium с установленным Playwright запустите `node test/checkout.cjs`. При использовании системного Chromium можно задать `CHROMIUM_PATH`. Тест блокирует любые запросы, кроме чтения локальных ресурсов из тестовой копии.

Фотографии в каталоге подписаны «NOMAD Coffee». Перед повторной публикацией проверьте, распространяется ли разрешение на сайт и открытый репозиторий.
